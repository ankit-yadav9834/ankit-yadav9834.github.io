Rapid Rent client →

A two-wheeler rental platform built for a local business in Ratnagiri. Ten vehicles, each carrying its own refundable deposit and rate card, priced across 3-hour, 6-hour, 12-hour, 24-hour and weekly slabs with separate per-hour and overtime rates.

The booking form quotes a live price as the customer picks a vehicle and a duration, then hands off to WhatsApp — the channel the business actually closes on. Server-rendered with a generated sitemap.xml, because a local rental business lives or dies on local search.

CarDekho Used Car Price Predictor →

A deployed Streamlit application predicting used-car prices from 15,000+ real listings. Preprocessing and feature engineering run through a scikit-learn ColumnTransformer, with a RandomForest regressor tuned by RandomizedSearchCV under cross-validation.

On top of the prediction sits a deal-rating engine comparing each result against market medians, plus feature-importance visualisations. Serialised model artifacts are cached, which cut load time substantially.

Algerian Forest Fire Prediction →

A Flask backend exposing a REST API for real-time fire-risk prediction. Linear, Ridge and Lasso regressions were tuned to predict the Fire Weather Index, with data processing, model inference and the API kept as separate layers so the thing was actually deployable.

Smart Campus: Wi-Fi Load Prediction 1st place →

First place at the Samatrix hackathon with Team A4. An end-to-end system predicting campus Wi-Fi bandwidth demand from device counts, exam and event schedules, weekday patterns and network conditions.

Historical-usage and rolling-average features were engineered on a full cleaning, EDA and preprocessing pipeline to capture temporal load patterns. Linear Regression and Random Forest were compared on RMSE, MAE and R², and the winner shipped behind an interactive interface for capacity planning.
